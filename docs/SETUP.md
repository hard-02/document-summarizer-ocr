# Setup Guide

## 1. Run locally

### Local models (default)

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-local.txt

streamlit run app.py                 # http://localhost:8501
# or
uvicorn web.server:app --reload      # http://127.0.0.1:8000
```

The first run downloads the public checkpoints (~1–2 GB). Fine-tuned weights in
`models/english/` or `models/hindi/` are detected automatically.

### Gemini backend (lightweight)

Streamlit (no torch):

```bash
pip install -r requirements.txt
export SUMMARY_PROVIDER=gemini
export GEMINI_API_KEY=your_key
streamlit run app.py
```

FastAPI instead:

```bash
pip install -r requirements-api.txt
export SUMMARY_PROVIDER=gemini
export GEMINI_API_KEY=your_key
uvicorn web.server:app --reload
```

No model download — summaries are generated by the Gemini API. For deployment,
put the settings in `.streamlit/secrets.toml` (copy from
`.streamlit/secrets.toml.example`) or in the Streamlit Cloud secrets.

## 2. Fine-tune

### Kaggle

1. [kaggle.com](https://www.kaggle.com) → **New Notebook** → GPU + Internet.
2. Import `notebooks/01_finetune_english_bart.ipynb` (English) or
   `notebooks/02_finetune_indicbart_hindi.ipynb` (Hindi).
3. Run All and download the output folder.

### Locally

```bash
pip install -r requirements-train.txt
python scripts/train.py --language en --epochs 2
python scripts/train.py --language hi --epochs 2
```

Place the outputs in `models/english/` and `models/hindi/`.

## 3. Publish to GitHub

```bash
cd document-summarizer-ocr
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/<you>/document-summarizer-ocr.git
git branch -M main
git push -u origin main
```

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| `streamlit: command not found` | Activate the venv, or `python -m streamlit run app.py`. |
| Gemini `API_KEY_INVALID` | Check `GEMINI_API_KEY`. |
| `MODEL_NOT_FOUND` | Set `GEMINI_MODEL=gemini-3.5-flash`. |
| `models/` not detected | Folder names must be `english` / `hindi` with `config.json` + weights. |
| PDF text empty | Scanned PDFs have no text layer (OCR was removed). |
